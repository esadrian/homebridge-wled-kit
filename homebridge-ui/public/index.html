Thank you for using WLED Kit

Control WLED-powered LED strips from the Home app via Homebridge.

What this plugin does
  • Exposes each WLED strip as HomeKit Light accessories (on/off, brightness, color, color temperature).
  • Optional Television-style preset inputs, segment lights, effect switches, and nightlight timers.
  • Network discovery for WLED devices on your LAN (mDNS + manual IP).
  • Real-time state via WebSockets (WLED v0.13+) with HTTP polling fallback.
  • Optional HyperHDR sync for Ambilight setups.
Prerequisites
  • Homebridge v1.8+ or 2.x
  • Node.js v20, v22, or v24 (LTS)
  • WLED firmware v0.13+ recommended for WebSockets
  • Homebridge and your WLED devices on the same network (or routable)
Quick start
  1. Open the Devices tab → Add device → scan or enter an IP.
  2. Enable each strip and expand it to configure presets and advanced options.
  3. Press Save at the bottom of this settings window.
  4. Restart Homebridge when the restart banner appears.
Troubleshooting
  • No devices found? Confirm WLED is online, mDNS works on your network, or add by IP.
  • Offline status? Check host/port, firewall, and that Homebridge can reach the strip.
  • Changes not applied? Press Save in this window, then restart Homebridge.
  • Debug logs: Set log level to Debug under Settings, reproduce, then check Homebridge Logs.
